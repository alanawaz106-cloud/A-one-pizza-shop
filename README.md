# A-One Pizza Shop 🍕

A modern, responsive pizza shop website built with HTML, CSS and vanilla JavaScript. It features four pizza flavours, three sizes, interactive size selection, a working demo cart and a mobile navigation menu.

## Menu and prices

| Size | Diameter | Price |
|---|---:|---:|
| Small | 6 inches | Rs. 700 |
| Medium | 9 inches | Rs. 1,000 |
| Large | 12 inches | Rs. 1,500 |

Flavours: Classic Cheese, Pepperoni Delight, BBQ Chicken and Veggie Supreme.

## Features
- Responsive design for desktop, tablet and mobile
- Four pizza cards with food photography
- Interactive size selector
- Add-to-cart, quantity controls and live total
- Demo checkout summary
- Mobile navigation menu

## Run locally
Open `index.html` in a browser. An internet connection is needed for the online food photos and Google Fonts.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the root of your repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important customisation
The checkout is a front-end demo only; it does not collect payment or send orders. Add your shop's confirmed WhatsApp number and connect an order workflow before using it for real customers.
